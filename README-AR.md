# تسنيم — نسخة فحص التلاوة بالذكاء الاصطناعي

## ما الذي تفعله هذه النسخة؟
- FastConformer يعمل محليًا داخل التطبيق عبر ONNX Runtime Web.
- النموذج الحالي يستقبل **16 kHz mono Float32** مباشرة، لأن استخراج الخصائص الصوتية مضمّن داخل رسم ONNX.
- CTC greedy decoding ينتج token IDs، ثم تتم مطابقة التسلسل مع `quran_ctc_tokens.json` لتحديد السورة والآية.
- التطبيق يعرض الآية المتعرّف عليها، درجة تطابق التسلسل، وثقة الإطارات، والمسافة التحريرية.

## حدود مهمة
هذا **ليس فاحص أحكام تجويد كاملًا**. FastConformer هنا للتعرّف على التلاوة ومطابقة الآية. الحكم على المد والغنة والإخفاء والإدغام ومخارج الحروف يحتاج طبقة صوتية/فونيمية متخصصة إضافية.

## GitHub Actions
الـworkflow في `.github/workflows/android.yml`:
1. يثبت npm dependencies.
2. ينسخ ملفات الويب إلى `www`.
3. ينسخ `onnxruntime-web` وملفات WASM محليًا إلى `www/vendor/ort`.
4. يضيف Android بواسطة Capacitor.
5. ينسخ المشروع إلى Android ويضع صلاحيات الموقع.
6. يبني `app-debug.apk` ويرفعه كـartifact.

## ملفات النموذج
النموذج `fastconformer_full_mixed.onnx` حجمه كبير (~85 MB)، وهو أقل من حد GitHub الفردي 100 MB، لكن يجب عدم ضغطه داخل Git LFS إلا إذا اخترت ذلك.


## ما تم إصلاحه في هذه النسخة
- **بناء الأندرويد**: خطوة الصلاحيات كانت تكسر ملف `AndroidManifest.xml` (تُدرج الوسم داخل `<manifest`) — صُحّحت مع التحقق من صحة XML. نسخ ملفات ONNX Runtime صار يشمل `.mjs` + `.wasm`، وأُضيفت اختبارات للتأكد من وجود 604 صفحة والنموذج.
- **أول تشغيل**: نص المصحف المرفق (`data/quran.json`) يُحمَّل تلقائيًا بدون إنترنت ولا حاجة لزر "تنزيل المصحف".
- **✨ PLUS**: كانت لا تفتح (دوال `Store.favorites` و`setSurahPosition` ناقصة). أُضيفت المفضلة والملاحظات ومواضع السور.
- **الصوت**: أُضيفت `getPlayableAudioUrl` و`audioCacheInfo` و`downloadReciter/downloadSurah` و`clearAudio` — تنزيل الصوت وتشغيله أوفلاين ووضع الأوفلاين صارت فعلية. السرعة والتكرار والفاصل تُطبَّق فعلًا.
- **المصحف**: زر التكبير يعمل ويبقى بعد تغيير الصفحة، وسُمح بالتكبير بالقرص. زر 📜 يفتح آيات الصفحة (استماع / مفضلة / ملاحظة / تفسير) وشريط "يُتلى الآن" بدل التظليل.
- **فحص التلاوة**: حساب الثقة كان دائمًا 0% (الآن softmax صحيح)، ورمز الفراغ يُستنتج من شكل المخرجات.
- **Service Worker**: الكود شبكة-أولًا (التحديثات تصل)، وكاش الصوت لم يعد يُمسح عند التحديث، وكاش `tasneem-v2`.
- **المزايا**: التعليم/الاختبار/التحدي/التذكير/الخصوصية/شكل المصحف/النسخ الاحتياطي صارت وظيفية. أُزيلت بطاقتا "الساعة الذكية" و"الاتجاه" (غير قابلتين للتنفيذ داخل WebView).
- **الحساب السحابي**: `global.CloudSync` كان يرمي خطأ (المتغير غير معرّف) — صُحّح.

## المصحف
- المصحف: *مصحف المدينة النبوية (الأزرق) — مجمع الملك فهد* — 604 صورة في `mushaf/pages/page-001.jpg` … `page-604.jpg` (رقم الملف = رقم صفحة المصحف).
- مُستخرج من ملف PDF الأصلي (صفحة الـ PDF = صفحة المصحف + 3)، ومقصوص بمربع موحّد لحذف الهوامش البيضاء، ومكبَّر 1.5× لوضوح أعلى.
- القارئ بملء الشاشة: الأزرار مخفية عند فتح الصفحة؛ اضغط على الصفحة لإظهارها/إخفائها، واسحب يمينًا للصفحة التالية ويسارًا للسابقة. يمكن إلغاء الوضع من ✨ PLUS ← شكل المصحف.

## الإشعارات
- **آية الافتتاح**: كل ظهور = آية جديدة بالترتيب (لا تتكرر نفس الآية). زر "قرأتها" يسجّل الآية المعروضة في الإحصائيات.
- **الأذان**: إشعار الأذان فيه زر **⏹ إيقاف الأذان** (يحذف الإشعار فيتوقف صوته).
- أيقونة `ic_stat_mosque` غير موجودة في المشروع: ضعها في `native-res/drawable/ic_stat_mosque.xml` وسيُنسخان تلقائيًا أثناء البناء.
- ⚠️ الواجهة تستدعي إضافة أندرويد اسمها `Tasneem` (ودجت آية اليوم، الصلاة على النبي عند فتح الهاتف، خدمة الأذان). كودها الأصلي (Java/Kotlin) **غير موجود في هذا المشروع**، لذلك لا يمكن تعديل إشعاراتها من هنا.
